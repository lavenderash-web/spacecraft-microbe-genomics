# Genome Quality Assessment

## Objective
Evaluate the quality of the draft genome assemblies used in the comparative genomics study.

## Tools
- QUAST — assembly statistics
- CheckM — estimated genome completeness and contamination

## Metrics
- Number of contigs
- Total assembly length
- N50
- GC content
- Estimated completeness
- Estimated contamination
